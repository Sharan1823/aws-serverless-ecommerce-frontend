# AWS Serverless E-Commerce Order Management System

## Overview

A full-stack serverless e-commerce order management application built using AWS cloud services.

## Features

- AWS Cognito Authentication
- JWT Authorization
- Create Orders
- Update Orders
- Delete Orders
- Order Status Tracking
- Search Orders
- Analytics Dashboard
- AWS SQS Integration
- AWS SNS Notifications
- CI/CD Deployment using AWS Amplify

## Tech Stack

### Frontend
- React.js
- Axios
- Tailwind CSS

### Backend
- Python
- AWS Lambda
- API Gateway

### Database
- Amazon DynamoDB

### Authentication
- AWS Cognito

### Messaging
- Amazon SQS
- Amazon SNS

### Deployment
- AWS Amplify
- GitHub

## Architecture

User → React → Cognito → API Gateway → Lambda → DynamoDB

Lambda → SQS → Notification Lambda → SNS

## Project Highlights

- Secure login using AWS Cognito
- Full CRUD operations
- Order status tracking
- Real-time analytics dashboard
- Event-driven architecture
- Serverless cloud deployment
